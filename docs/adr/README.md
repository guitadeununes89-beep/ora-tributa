# Architectural Decision Records

Decisões arquiteturais relevantes devem ser registradas **antes** da implementação.

## Processo

1. copie `0000-template.md` para o próximo número sequencial;
2. marque como `Proposta` durante discussão;
3. registre contexto, decisão, consequências e alternativas;
4. após aprovação, marque como `Aceita`;
5. nunca apague ADR aceito: crie outro que o substitua.
